# Contributing to AI-Powered Personal Finance Coach

Thank you for your interest in contributing to this project! We welcome contributions that help improve the quality and functionality of the Personal Finance Coach.

## How to Contribute

### Reporting Bugs

- Open an issue in the GitHub repository
- Provide a clear title and description
- Include detailed steps to reproduce the bug
- Mention your Java version and operating system (if relevant)

### Suggesting Features

- Open a new issue with the title "Feature Request: ..."
- Clearly describe the suggested feature and its benefits
- Examples: Additional budgeting rules, data export options, improved reports, etc.

### Submitting Pull Requests

1. Fork the repository
2. Create a new feature branch:
   ```bash
   git checkout -b feature/your-feature-name

3. Make your changes
4. Ensure the project builds successfully:
   ```Bash 
   mvn clean compile
5. Commit your changes with a clear message:
   ```Bash 
   git commit -m "Add: description of your changes"
6. Push to your branch:
   ```bash
   git push origin feature/your-feature-name
7. Open a Pull Request and provide a detailed description of your changes
